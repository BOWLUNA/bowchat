# bowchat

**状态：规划中 · Status: planned.** 尚无可用版本。

> **鸿蒙原生 AI 聊天软件**，以**群聊**为核心，内置轻量本地记忆与小说生成，后续拓展到全平台。

⚠️ **这是软件，不是 DSH 插件**——所以它不带 `dsh-` 前缀。

## 想做成什么样

对标 Rikkahub 这类 AI 聊天客户端，但有两个根本差异：

**1. 群聊是英雄模式，不是附属功能**

大多数 AI 聊天软件只有"你 ↔ 一个模型"。而真实需求是**多个角色同场**：各有独立人设、能互相看到发言、能自然轮流而不靠 @ 唤起。这也是本项目最想解决的问题。

**2. 内置轻量的创作与记忆**

- **本地记忆系统**：不依赖云端，会话之间的记忆存在本地
- **简化版小说生成**：设定集 + 章节推进，轻量到一个聊天软件该有的程度

## 目标

- **超越而非模仿**：Rikkahub 有的功能都要有；它没有的（群聊、创作、记忆）尽量加
- **鸿蒙原生优先**：先做 HarmonyOS 原生，再向其他平台拓展
- **本地优先**：用户数据尽量留在设备上

## 已知的大工程属性（诚实说明）

这是一个**产品级项目，不是插件**，工程量远大于本账号下的其他仓库。它的几个核心机制其实**应该先在 DSH 插件里验证**，再搬进软件：

| 软件里的模块 | 先在插件里验证 |
|---|---|
| 群聊多角色编排 | [dsh-agent-group](https://github.com/BOWLUNA/dsh-agent-group) |
| 角色数据与角色卡 | [dsh-sillytavern](https://github.com/BOWLUNA/dsh-sillytavern) |
| 小说设定与推进 | [dsh-novel](https://github.com/BOWLUNA/dsh-novel) |
| 沉浸式对话体验 | [dsh-rp](https://github.com/BOWLUNA/dsh-rp) |

**顺序不能反**：先在插件里把机制跑通（成本低、迭代快），再搬进软件。
