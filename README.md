# dsh-screen-capture

**状态：规划中 · Status: planned.** 尚无可用版本。

## 要解决什么

遇到"这个报错长什么样""这个界面哪里不对"时，最快的方式是**截图**，而不是把屏幕内容抄成文字。dsh 支持贴图，但**采集**这一步是断的（要手动截图、存盘、再拖进对话）。

## 计划做什么

- **截屏 / 选取屏幕区域**，一步进入当前会话的上下文
- 可选 **OCR**：把截图里的文字同时以文本形式给出，便于检索与引用
- 可选：窗口/显示器选择、多屏支持

## 不做什么

- **不**做屏幕录制，**不**做录屏回放
- **不**做常驻监控或定时截图——**只在用户显式触发时采集**
- **不**与 `vision` 类插件重复：那些负责"让文本模型看懂图"，本项目只负责**把图拿到手**

## 隐私立场

截屏可能包含密码、聊天记录等敏感信息。设计上：采集**必须由用户显式触发**，截取范围**由用户框选**，不提供后台自动采集。
